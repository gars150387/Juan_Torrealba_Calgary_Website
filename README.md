# Juan Torrealba | Calgary Real Estate

Static website source for the published Calgary real-estate landing page.

## Run locally

Open `dist/index.html` in a browser, or serve the project with any static-file server.

## Main files

- `dist/index.html`: full landing page, styles, links and Motion animations.
- `.openai/hosting.json`: hosting configuration used for the published version.

## Integration note

Evertrust listing URLs are opened in a new tab because the source site blocks external iframe embedding through Cloudflare and `X-Frame-Options: SAMEORIGIN`.
